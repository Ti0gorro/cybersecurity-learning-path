# AegisTech — Arquitectura de seguridad por fases

AegisTech es una organización ficticia con aplicaciones web, APIs, servidores y endpoints. Este repositorio reúne la documentación técnica de una arquitectura empresarial de ciberseguridad. Cada fase describe un dominio de seguridad y su relación con los demás componentes.
