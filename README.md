# Cybersecurity Learning Path 🛡️

**Ruta autodidacta de 18 meses | Chile | GRC + Blue Team + Security Engineering + DevSecOps**

Repositorio central de aprendizaje, laboratorios reproducibles y evidencias profesionales para SOC L1, GRC, seguridad defensiva y DevSecOps.

> **Estado:** preparación inicial. Ningún laboratorio se considera completado sin evidencias reproducibles. Los entornos y la empresa de prácticas son simulados; no representan experiencia laboral formal.

## Proyecto transversal: AegisTech

[AegisTech](company/aegistech/README.md) es una empresa ficticia de servicios web y API con datos totalmente sintéticos. La ruta incorpora progresivamente inventario y riesgos, hardening, monitoreo, remediación, despliegues seguros y detección automatizada.

## Metodología

Distribución orientativa: **30% teoría · 50% práctica · 20% documentación**. Cada módulo se aprueba con fundamentos explicados, implementación reproducible, evidencias, evaluación y limitaciones documentadas. Los repositorios técnicos independientes se crearán cuando tengan contenido sustantivo.

## Seguridad y licencias

Únicamente se estudian sistemas propios o autorizados. No publicar credenciales, datos personales, logs sensibles, secretos ni textos completos de normas comerciales ISO.
