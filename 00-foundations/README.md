# Fase 00 · Contexto y modelo de amenazas

Esta fase define el escenario técnico de AegisTech: sus activos, servicios, usuarios, flujos de información y límites de confianza. El análisis identifica superficies de exposición y escenarios de amenaza que sustentan el diseño de controles.

## Componentes

- Inventario lógico de activos y dependencias.
- Diagramas de arquitectura y flujos de datos.
- Límites de confianza y puntos de acceso.
- Confidencialidad, integridad, disponibilidad y trazabilidad.
- Amenazas asociadas a componentes y procesos.

Este contexto proporciona la base para la [evaluación de riesgos](../01-governance-risk-compliance/README.md).
