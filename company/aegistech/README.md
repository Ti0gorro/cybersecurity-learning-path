# AegisTech: caso de estudio transversal

Organización **enteramente ficticia** que presta servicios web, API y almacenamiento de información de clientes. Todos los datos de empleados/clientes serán sintéticos.

## Alcance inicial simulado
- Aplicación web y API REST.
- Base de datos con datos ficticios.
- Repositorio Git y pipeline CI/CD.
- Endpoints Windows/Linux virtualizados.
- Administradores y usuarios de prueba.
- Firewall y segmentación de laboratorio.

## Progresión
1. Riesgos, políticas y controles (GRC).
2. Implementación y hardening (Infraestructura).
3. Monitoreo, detección e incidentes (SOC).
4. Hallazgos y remediación (Vulnerabilidades).
5. Integración de seguridad al desarrollo (DevSecOps).
6. Detección y automatización integradas (Capstone).

**Aviso:** no constituye auditoría externa, certificación ni cumplimiento legal real.
