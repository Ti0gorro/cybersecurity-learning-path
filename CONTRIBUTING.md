# Convenciones de trabajo

- Ramas: `feat/modulo-tema`, `docs/tema`, `fix/tema`.
- Commits: `docs: ...`, `feat: ...`, `test: ...`, `fix: ...`.
- Para marcar un laboratorio como terminado, agregar objetivo, entorno, procedimiento, resultados, evidencia y limitaciones.
- Nunca subir contraseñas, tokens, llaves privadas, direcciones IP públicas propias, información personal ni logs sensibles.
- Las pruebas ofensivas se realizan únicamente en sistemas propios o entornos autorizados.
- Toda modificación relevante debería vincularse a una Issue.
